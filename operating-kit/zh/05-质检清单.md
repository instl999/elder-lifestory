## 事实

- [ ] **每个名字都按家里人的写法写。** 以家属核对单的答复为准，而不是以转写稿为准，
      因为语音识别会把名字写错，而且错得理直气壮。
- [ ] 各章之间的日期一致
- [ ] 亲属关系正确、前后一致（没有人成了自己的姑妈）
- [ ] 地名用*当时*的叫法，必要时注明今天的名称
- [ ] 没有把在世的人写成已故，也没有把已故的人写成在世
- [ ] 文中隐含的年龄与写明的年份相符

> 人名、日期和亲属关系是 §18 规定的“零错误”项目。这张清单上的其他项目都是判断题，只有这几项是对错题。

## 声音

- [ ] 大声读一页。听起来像一个人，还是像一个模型？
- [ ] 老人特有的说法保留下来了
- [ ] 没有老人绝不会用的词
- [ ] 没有残留的转写杂音（“嗯”“那个”、说了一半的话、重复的词）
- [ ] 轻描淡写的地方仍然轻描淡写。最典型的失败，就是把一句干巴巴的话抬高成煽情的句子

**检验标准：** 孙女读到这里，能听见奶奶的声音吗？如果您拿不准，答案就已经有了。

## 编造

模型最危险的产出，是那些谁也没要求、却看起来很可信的细节。

> **自动检查不覆盖这一节。** `lifestory check` 核实的是引用和引语。一个像“这意思她听得出来”这样的句子，
> 以讲述人的口吻写出、老人却从没说过，放在书稿中间，检查照样全部通过。一个既不是引语、
> 也不是事实条目的编造细节，没有任何可以对照的东西。在这样的句子和印好的书之间，只有这一节挡着。

- [ ] 没有编造的天气、饭菜、衣着或室内陈设
- [ ] 没有编造的对话：每一句带引号的话都追溯过
- [ ] 没有编造的内心活动。“她一定觉得……”是换了一种礼貌说法的编造
- [ ] 没有编造的因果：两件事先后发生，不等于前一件导致了后一件
- [ ] 没有“凑整”：一个大概的年份，读起来仍然应该是大概的

**先从 `lifestory check` 在 “Spot-check these first”（优先抽查）下列出的句子开始**（溯源表里也按章列出了）。
它们是和录音内容最不相像的句子。在普通话演示里，它列出的 11 句中有 6 句是编造的，其中包括“病家只得典衣当物”，
录音里从没提过当东西的事。另外 5 句是合理的转述，或是转写稿本身有错的词。它看不出两件真事之间被编造出来的联系
（比如“这已经是他第二回说不要紧了”，用的全是录音里的词，连起来的意思却是编的），这种要您自己读出来。

## 尊严

- [ ] 没有人被写成笑柄，包括已经过世的人
- [ ] 苦难没有被美化
- [ ] 贫穷、疾病和悲伤是被记录下来，而不是被拿来制造效果
- [ ] 最后没有一段替老人总结“人生意义”的话
- [ ] 讲述人读了能认出自己，而且不会觉得被摆布

## 隐私与同意

- [ ] 书里任何地方都没有标为私密（`restricted`）的内容
- [ ] 每一项放行都有放行说明，写明是谁决定的
- [ ] 书中被写得不太好看的在世的人：公平吗？必要吗？站得住吗？
- [ ] 没有与叙事无关的住址、财务细节或医疗细节
- [ ] 提供资料的家属按他们希望的方式署名

> 如果讲述人放行了一些敏感内容，而您心里不踏实，在付印之前再平实地问一次。印刷之前，放行都可以撤回；
> 印出来以后，它就永远留在这个家里了。

## 家庭矛盾

- [ ] 有争议的说法按有争议来呈现，不做裁决
- [ ] 没有仅凭一个人的说法，就指控任何在世的人
- [ ] 写到疏远或断绝关系时，不站在任何一边
- [ ] 书中提到的每一位家人，会觉得自己被公平对待吗？

## 照片

- [ ] 每一条图注里的人物都正确（以家属核对单为准）
- [ ] 任何修复或上色都有注明
- [ ] 原件另外保存
- [ ] 没有把生成的图像当作真实照片呈现
- [ ] 分辨率警告已经解决，或已明确接受

## 印制

- [ ] 页数和书脊宽度与印刷规格一致
- [ ] 正文字号 12 磅或更大，讲述人自己要能看得清
- [ ] 前面的部分：书名、版权页、同意声明、目录
- [ ] 后面的部分：关于本书、致谢、提供资料的家属
- [ ] 文件名和文件属性里没有泄露任何私密信息
