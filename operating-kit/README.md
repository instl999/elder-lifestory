# Operating kit · 操作文档

The Phase 0 documents a case needs, in English and Chinese. Documents the family
reads or signs are written for reading aloud in their language, not translated
line by line.

第 0 阶段一个案例需要的全部文档，中英文各一套。家属要读、要签的文件，是按各自的语言为当面朗读而写的，
不是逐句翻译。
